## 使用约定

1. **事实源唯一**：机制修改只改本库文件；机制文档按主题独立成篇（拆分原则：可独立维护、可独立引用、单篇不超过一个主题）。
2. **SOUL 引用策略**：SOUL 只引用本库入口（README.md）或对应文件，不引用 `文档/` 路径；机制内部结构调整时无需改动 SOUL。
3. **一主题一文件**：机制文档按主题独立成篇；新增机制按编号递增。
4. **交叉引用**：本库文件间用文件名相对引用（如 `01-需求分级.md`），不写 `文档/` 路径。
5. **与资料区边界**：给人看的资料（机制与方案 / 团队模板 / 工程指南 / 学习笔记）留在 `文档\`；本库只管 agent 协作规则与数据。
6. **审计报告**：数据产物（每轮审计报告）归档 `D:\OpenMausBot\审计\`，不入本库（本库只放机制与聚合表）；判定标准见 [03-工作流与产物.md](03-工作流与产物.md) 接缝规则 7。
