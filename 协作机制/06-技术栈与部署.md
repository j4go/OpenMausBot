# 技术栈与部署

> 本文件为「新团队初始化包」快照副本（snapshot: 2026-09-13），泛化自来源仓库机制库（旧版本文档已清理，本文件为事实源）。
> 占位章节已于 **2026-09-13 OMB 团队初始化**时按 fork 仓库（OpenMausBot v0.1.76）实况回填；后续技术栈变化（如升级 Node / 换构建工具）由对应切片同步更新本表。

| 项 | 值（2026-09-13 回填） |
|---|---|
| 后端 | TypeScript 服务端 `server/`（OpenMausBot 核心服务，Node ≥24 以 `--experimental-strip-types` 直跑 TS；引擎约束 `node >=24`，包管理 pnpm@10.33.0 corepack 固定） |
| 前端 | React 19 + Vite 7 SPA（`src/`）+ Electron 43 桌面壳（`electron/`）；monorepo（pnpm workspace：`apps/docs`、`shared`、`companion`、`server`、`electron`、`cloudflare`、`enterprise`、`ios`、`android`、`scripts`、`deploy`、`third_party`） |
| 数据库 | SQLite（Node 内置 `node:sqlite` / DatabaseSync，无第三方驱动）；数据文件 `~/.openmausbot/messages.db`（文件权限 0600），同目录存会话/凭据加密文件（*.json.enc）；开发数据目录 `.omb-dev-data\`（gitignore，含尾随空格目录名的历史遗留） |
| 构建验证 | `pnpm install`（corepack 固定版本）→ `pnpm typecheck`（`tsc -b && tsc -p tsconfig.server.json`，门禁）→ `pnpm lint`（oxlint --deny-warnings）→ `pnpm test`（vitest run + broker:test + test:electron + test:packaged-server，全量较重，按触达面选用）；打包 `pnpm package:win`（electron-builder） |
| 部署通道 | 桌面应用打包产物（本地运行，无测试服）；Cloudflare 组件（composio-broker / control-plane 的 `wrangler deploy` 为生产通道，**默认禁动**）；本地部署默认 dry-run，需 runbook + 用户批准 |
| 版本规则 | SemVer（package.json `version` 字段），当前 0.1.76；版本提升走对应切片评审 |

**纪律（保留，不因占位而豁免）**：

- 部署类操作遵守 SOUL 纪律：默认 dry-run、双重批准；无 runbook 且无本轮明确批准时不得真部署。
- 构建与验证是 CI 等价门禁（固定闸），见 01-需求分级.md 原则 8。
- 单机项目只用本地 git（无远程 origin）时，按 01-需求分级.md 原则 10 的分支决策执行。
