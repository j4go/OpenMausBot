# haitian-pw-0.6.0 打包说明

## 给谁

海天现场安装同事。解压后整夹替换 Codex skills 里的 `product-workflow-suite/`。

## 包名

`pw-suite-haitian-v0.6.0-20260908.zip`

解压后根目录应是：

```text
product-workflow-suite/
  00-本版说明.md
  00-打包说明.md
  01-用户交付-本版修改问题清单.md
  VERSION
  product-*/
  repo-wiki/
  superpowers/
  ...
```

## 打进包

- 全部 `product-*` skill、`repo-wiki`、`superpowers`
- `code-wiki/` 源码留在 git，不打进 0.6.0 安装 zip（接到工作流是 0.7.0 的事）
- `00-本版说明.md`、`00-打包说明.md`、`01-用户交付-本版修改问题清单.md`、`00-继承说明.md`
- `VERSION`、`RELEASE.json`、`SHA256SUMS.txt`、`scripts/release-integrity.mjs`
- `workflow-manifest.json`、`package-excludes.txt`

## 不打进包

- `.git/`、`node_modules/`、`tests/`、`coverage/`
- `package.json`、`package-lock.json`（仅开发测脚本用）
- 顶层 `evals/`（评测过程产物、对照报告）
- `sandbox/`（评测夹具）
- `docs/` 内部计划、`99-内部-*`

`product-*/evals/` 打进包。那是 skill 自己的理解与评估文档，不是评测过程产物。

## 安装核对

1. 替换后重启 Codex，开新会话。
2. 先读 `00-本版说明.md`。
3. 对 Codex 说：读本项目 AGENTS.md。连跑要人点名。
4. 复现问题带上版本号 haitian-pw-0.6.0。
5. 核一下来源和文件有没有被改过：

```bash
node scripts/release-integrity.mjs verify --expected-version haitian-pw-0.6.0
```

6. 在客户项目根目录跑一次：

```bash
node "<套件安装夹>/product-workflow/scripts/migrate_suite.mjs" .
```
