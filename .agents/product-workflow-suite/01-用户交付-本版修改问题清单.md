# haitian-pw-0.6.0 修改问题清单（给安装同事）

发布：2026-09-08

装这一版后按表核对。现场还碰到已经改过的问题，反馈版本名 haitian-pw-0.6.0 和步骤。

## 和 0.5.0 比改了什么

1. 「做个需求」自己开全流程 — `$product:workflow` 要你点名才跑。拿不准用 `$product:ask`。
2. 写完 PRD / 计划直接请批 — 先跑 `$product:review`（规格、能不能判定、有没有事实）。过不了就停在 Draft。
3. 命令太长记不住 — `$product:plan`、`$product:kickoff`。`$product:开工` 还能用。
4. 门户命令过时 — 按 Limix CLI 0.6.1：`limix project` / `limix requirement`（`issue` 同义）。
5. 交付件怎么管 — init 会问：只要 git、只要门户，还是两个都用。两个都用时，同一批 Reviewed 源头要已提交、已上传。
6. 审查板被传到门户 — 看板只写 `.review-board/`。根上旧的 `index.html` 迁到 `legacy/`。别把看板拷回切片根。
7. 空目录不会 Git — `$product:init` 问仓库地址后 clone。目录里已经有 git 就跳过。
8. 遗留仓追覆盖 — 增量覆盖。新增代码要有单测。不可测的遗留行摊给用户，默认窄排除。

## 这一版不做

- `code-wiki` 接到工作流（不打进 zip；0.7.0）
- `ticket.md`、交付件分层、产物文件名缩短（0.7.0）
- 安全扫描进开发门禁（0.7.0；GitLab CI 强制门禁更往后）
- 加密需求、飞书读图（#27）
- 本机 Codex 沙箱 unelevated（#7 / #38 的 IT 侧）仍按问题 7 手册

## 0.5.0 / 0.4.2 / 0.3.0 里已经改过、这一版接着用的

lite 短 PRD、一键迁移、看板补自动化测试 tab、impeccable 现场自己装、三端栈层、#21 默认一阶段一批准、#14 / #35 单测和 Git Hook 是建议不挡编码、看板收进 `.review-board/`。
