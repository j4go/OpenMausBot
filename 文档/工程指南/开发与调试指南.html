2凭据机制（项目特色，务必了解）

禁读边界仓库根 .local-credentials.env

禁读、禁提交（gitignore），properties 格式两行：

DB_USERNAME=你的用户名
DB_PASSWORD=你的密码

注入机制application.yml

spring.config.import: optional:file:../.local-credentials.env[.properties]

username/password 占位符无默认值，缺失即 fail fast（防止悄悄连错库）；自动化测试用 H2 内存库 + 环境变量 DB_USERNAME/DB_PASSWORD 覆盖，不依赖 MySQL。

⚠️ 坑：.env 不是 Spring 原生配置扩展名，config import 必须带 [.properties] 格式提示，否则 optional 会静默吞错、占位符原样传给 JDBC，表现就是启动报 Access denied。

5调试

端方式要点
后端（Java）IDE 断点：IntelliJ 打开 backend\ 运行主类并断点调试（最直观）
远程调试：命令行启动 + IDE attach 5005		mvn spring-boot:run "-Dspring-boot.run.jvmArguments=-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=*:5005"；日志实时输出在启动窗口
后端 API 冒烟curl 健康检查（口径与冒烟计划 S1 一致）curl -i http://localhost:8080/api/tickets 期望 200 + 工单数组；POST 冒烟工单：curl -i -X POST http://localhost:8080/api/tickets -H "Content-Type: application/json" -d '{"title":"冒烟工单"}'（title 必填，字段以 prd/实体为准）
前端（Vue 3 + Vite）HMR 热更新，改代码即时生效类型检查 npm run typecheck（构建/CI 前置门禁）；看 /api 请求是否代理成功（F12 → Network → 过滤 api）；若 502/504 多半是后端 8080 没起来
前端组件调试浏览器 Vue DevTools 扩展查组件树 / 状态 / Pinia（若引入）

7排障速查表

症状原因处理
后端启动即失败，日志 Access denied.local-credentials.env 凭据缺失/格式错，或 config import 丢了 [.properties]检查文件两行 DB_USERNAME=/DB_PASSWORD=（properties 格式，等号两侧无空格）；确认 import 写法见 §2
后端失败，日志 Unknown database 'demo'demo 库未建执行 §1 建库语句后重启
后端失败，连接超时MySQL 未启动启动 MySQL 服务；Test-NetConnection localhost -Port 3306 应 True
端口 8080 / 3000 被占上次进程未退netstat -ano | findstr :8080（或 3000）→ taskkill /PID <pid> /F
前端报 module not foundnode_modules 缺失/过期npm install（脚本已自动处理缺失）
前端页面 502/504vite 代理目标（后端 8080）没起来先启动后端；frontend\vite.config.ts proxy 指向 http://localhost:8080
改配置不生效Spring 缓存了旧配置重启后端进程（Ctrl+C 再 mvn spring-boot:run）
