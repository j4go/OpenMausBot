## 二、各二开项详情

### 1. 窗口图标修复（`72363b70`）
- **问题**：Windows 任务栏显示白色空图标。根因：主窗口 icon 用单张 1024x1024 PNG（Electron Windows 任务栏渲染 PNG 易出白块，Joplin/Signal 同款问题）
- **改法**：`electron/main.mjs` 新增 `WINDOW_ICON`（win32 用 `resources/app-icon.ico`，其他平台回退 PNG）；两处 `BrowserWindow`（主窗口 ~1539 行、viewer ~1209 行）`icon:` 改用它
- **素材**：`build/icon.ico`（项目已有，多尺寸 256~16px 32bit）复制为 `electron/resources/app-icon.ico`
- **验证**：dev 版 + 打包版窗口图标非白像素 ~79%（修复前接近 0%）
- **官方更新风险**：官方若改 `main.mjs` 窗口代码，merge 冲突时保留 `WINDOW_ICON` 逻辑

### 2. prepare-browser 修复（`d560455d`）
- **问题**：`pnpm build:browser` 最后 `renameSync(stage, destination)` 报 EPERM（安全软件锁目录 rename）
- **改法**：`scripts/prepare-browser.mjs` 改为 `rmSync(旧目录) + cpSync(逐文件复制)`（复制不受目录锁影响）；import 补 `cpSync`
- **验证**：build:browser 成功（agent-browser 0.36.0 + Chromium 152）
- **官方更新风险**：低（官方一般不改此脚本）

### 3. 字体 Maple Mono NF CN（`aadbb3e4`）
- **问题**：官方无字体设置项，用户要统一界面/代码块字体为 Maple Mono NF CN
- **改法**：`src/styles.css`
  - `--font-sans` 全部 9 处（`:root` + 8 套皮肤，含 daylight 小写变体）前面加 `"Maple Mono NF CN"`
  - 新增 `@theme` 块覆盖 `--font-mono`（Tailwind v4 默认值），Maple 打头
  - 原字体栈保留第二位作回退
- **验证**：构建产物 CSS：`--font-sans:"Maple Mono NF CN"` 9 次、`--font-mono:"Maple Mono NF CN"` 1 次、旧定义残留 0
- **官方更新风险**：官方新增皮肤时新皮肤 font-sans 需同样加 Maple；`@theme` 块 merge 时保留

### 4. 开发工具 dev.ps1（`db1fe57a`）
- 项目内 Node 24 环境（`.tools\node24`），动作：status/install/build/typecheck/lint/server/web/desktop/package/stop，-AutoStop 自动关官方版
- `.gitignore` 新增：`.tools/`、`.omb-dev-data/`

### 5. bat 脚本（未提交）
- `构建-二开版.bat` → `build-local.ps1`：精简构建流程（跳过 Android 工具）+ 预解压绕过安全软件锁（electron 缓存持久副本 `bat/electron-cache/`，防清理；**精确匹配 node_modules 实际版本防过时**，版本不符自动下载新版并回填副本）+ 失败重试
- `启动-二开版.bat` → `run-local.ps1`：代理探测 + 启动 `release\win-unpacked\OpenMausBot.exe`（日志 %TEMP%\omb-local-*.log）
- `调试-后端.bat` / `调试-前端.bat`：调 `dev.ps1 server/web`
- 共享 `omb-common.ps1`：代理探测 + NO_PROXY
