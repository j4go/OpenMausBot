OMB vs Rakazo

同一赛道的两个独立实现：理念与实现对比 —— 2026-09-12

结论经 GitHub 核实 OMB 本机在用 Rakazo v0.1.6 beta

核心结论暂不装 Rakazo

两个项目均为 2026-08 独立开源、Apache-2.0、互不为 fork（rakazo 吸收的 millson1 是瑞士 Millson，非 milind-soni）

OpenMausBot
"Your own team of AI bots, in a chat app"
定位本地桌面聊天应用为产品中心
数据本地优先，~/.openmausbot 文件，无数据库
模型BYO 本机 CLI（复用 claude/codex/grok 登录）
架构React(:5199) + harness(:8799)，HTTP+SSE
分发mac / Windows / Ubuntu 安装包
体量1691 commits · 2.55k★ · 193 issues
VS
Rakazo
"AI teammates you actually own"（VISION.md）
定位持久化 AI 队友平台，三端共用一 API
数据服务端优先：Postgres + Prisma，bots 常驻
模型BYO 凭据，经 Pi 网关，服务端持有
架构Postgres + Graphile Worker；web/Electron/Expo 瘦客户端
分发Docker Compose；桌面只有 mac + Linux
体量828 commits · 2.33k★ · 9 issues

Rakazo 独有卖点（OMB 没有）

能力说明
语义记忆Supermemory / Serenity（按 space 选择，带 SSRF 防护），OMB 为文件记忆
语音4 种（ElevenLabs / OpenAI / Cartesia / Fish Audio），OMB 仅 ElevenLabs
Team Computer共享浏览器身份；OMB 沙箱为 Box 云桌面 / 本地 VM / 宿主 CUA
工具源Pipedream Connect + 自装 Treg + 远程 MCP + OpenAPI，比 OMB 的 Composio 更宽

关键事实

  • Windows 是分水岭：OMB 有成熟 Windows 安装器（本机在用）；Rakazo v0.1.6 发布资产只有 mac dmg/zip + Linux AppImage，无 .exe。
  • 本地体验：OMB 装完即用；Rakazo 本地跑也要 Docker Engine + Postgres。
  • 社区体量：stars 接近，但 OMB 提交/issue 流量明显更大——迭代更快也更"吵"，Rakazo 更收敛。
结论：暂不装。 Windows 桌面主力（Rakazo 无 Windows 桌面端，只能浏览器 + Docker/Postgres）+ OMB 已深度使用，迁移成本高收益低。 它的主场是 24h 服务器常驻 + 手机/网页随时访问（OMB serve --tunnel 也能做到）；最低成本尝鲜 = VPS 跑 install-images.sh，浏览器体验两天，与 OMB 互不冲突、随时可删。等 Rakazo 出 Windows 桌面版再重新评估。
