## html 与 md 的关系

- **同名成对**（如 `工作流方案总结与借鉴.md` + `.html`）：md 为事实源（agent 与 git diff 友好），html 为可视化版（提炼，人看）；内容**不完全等价，以 md 为准**。
- **仅 html**（`工程指南/开发与调试指南.html`、`机制与方案/工作流机制演进.html`、`研发流程总览.html`、`适配清单可视化.html`）：可视化 / 单页指南。
- **功能型仅 md / 脚本**：`团队模板/omb-team.botmrr.md`（导入模板）。

## 维护约定

- 新增文档按主题归入对应目录：机制方案 → `机制与方案\`；模板 → `团队模板\`；操作手册 / 二开档案 → `工程指南\`；OMB 平台知识 → `OMB学习笔记\`。
- 新增可视化 html 一律用**中文文件名**。
- **机制内容（agent 协作规则 / 状态机 / 度量）一律写 `协作机制\`，不写本区**。
- 文档更新优先改 md 事实源；html 与 md 出现偏差时以 md 为准并同步 html。
- `文档\` 剪切不影响 agent 协作（SOUL / Section Context / AGENTS.md 均指向 `协作机制\`）。
- 从 Demo 迁移的 3 个文件（环境搭建配置指南.md/.html、开发与调试指南.html）方法论层保留、实值层待 OMB 化改造，改造前**勿照做其中 Demo 技术栈命令**。
